PUBLIC DATA / 実行済みの開発例

SNS分析の開発例：公開データを使った関連性分類

宿泊分野に関係する文章かを、開発中のモデルで分類した例です。クラウドワーカーが作成した疑似レビューと、架空の宿泊相談を演じた対話データを使用しています。実際のSNS投稿やNagiportのお客様の声ではありません。

以下は2026年10月14日に実行したEmbeddingGemma FP32・既存18定義方式の保存結果です。見せ方を説明するために選んだ4件で、実SNSでの精度や導入実績を示すものではありません。特定の店舗・企業との関連性、感情、不満・要望は、この例では判定していません。

表示の「情報不足」はモデルが返す分類名で、運用上の「判定保留」とは別です。文章は推論に入力した単位の全文を掲載しています。

出典・ライセンスを確認する

01

関連あり（F008）

データの種類：疑似ホテルレビュー

別府にある老舗の温泉旅館でした。 桜が咲く頃に、大人2名で宿泊しました。 泉質がとてもよく、長旅の疲れが癒やされました。 部屋からの景観もよく、満開の桜を見ることができました。 スタッフの方の対応はとても親切でした。 部屋は隅々まできれいに清掃されており、快適に過ごせました 夕食はバイキング形式でしたが、とても豪華で満足度が高かったです。 朝食は部屋でのんびり食べることができ良かったです。 部屋から見る夜景もきれいでした。 チェックアウトの際のお見送りも嬉しく感じました。

モデルの出力：関連あり

02

無関係（F007）

データの種類：疑似観光地レビュー

愛知県にある●●民族館は、歴史も分かるし、詳しい展示などオススメです。 名古屋駅からバスが直行便で出ているのでアクセスもいいですし、無料バスも月に1回あるのは穴場です。 私なら隣の●●民族の料理を出すレストランも寄るのが流れです。

モデルの出力：無関係（宿泊分野に対する分類）

03

情報不足（F004）

データの種類：架空の宿泊相談の顧客発話

はい、禁煙で大丈夫です。

モデルの出力：情報不足

04

見直しが必要な出力（F074）

データの種類：架空の宿泊相談の顧客発話

駅から宿までのバスがあると助かります。

モデルの出力：情報不足

比較用のAI暫定ラベル：関連あり

確認コメント：宿までの移動条件を述べていますが、モデルは「情報不足」と分類しました。出力をそのまま正解として扱わず、確認が必要な例です。比較用ラベルもAIが作成したもので、人による正解確認は未実施です。このコメントはモデルが生成した判定理由ではありません。

出典・ライセンス

例1・2：Yuta Hayashibe / Megagon Labs, Quasi Japanese Reviews（2023）。クラウドワーカー作成の疑似レビュー。CC BY 4.0。
出典：Quasi Japanese Reviews
原データ：例1 quasi_japanese_reviwes.hotel.00217、例2 quasi_japanese_reviwes.spot.00089。

例3・4：Yuta Hayashibe / Megagon Labs, Accommodation Search Dialog Corpus。関連文献：Self-Contained Utterance Description Corpus for Japanese Dialog, LREC 2022, pp.1249–1255。架空の宿泊相談サービスでの役割対話。CC BY 4.0。
出典：Accommodation Search Dialog Corpus
原データ：例3 data/main/dialog/text/102.tsv の14行目、例4 data/main/dialog/text/174.tsv の16行目。

ライセンス：CC BY 4.0
加工：元データからレビュー単位・顧客発話単位で選び、評価入力と同じ単位で掲載しています。対話の前後の文脈と話者・時刻などの列は含めていません。分類結果・確認コメントはNagiport側で追加しています。掲載本文を宣伝用に書き換えていません。原著者・配布元によるNagiportへの推奨・保証を意味しません。元データはライセンスの無保証条件に従います。
